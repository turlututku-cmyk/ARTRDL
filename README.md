# Demon List Template

A static, no-build website for a Geometry Dash demon list: ranked list, leaderboard (points are automatic), roulette and packs.

Layout by TheShittyList (https://tsl.pages.dev). Please keep the credit on the main page.

## Start

1. Run it: `powershell -ExecutionPolicy Bypass -File serve.ps1`, then open http://localhost:5174
2. Follow **GUIDE.md** step by step. Everything you need to change is explained there.

Your content lives in the `data/` folder (plain JSON files). Search the project for
`EDIT:` to find every spot in the code meant to be changed.
